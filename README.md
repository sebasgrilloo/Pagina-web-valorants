#  RadiantCoach

Landing page de una academia de **coaching de Valorant**, con estética inspirada en el propio juego: tipografía Teko, paleta roja/oscura y botones con corte angular.

>  Proyecto de demostración / maqueta de diseño web. Valorant es una marca registrada de Riot Games, Inc. Este proyecto no está afiliado ni respaldado por Riot Games.

##  Características

- Diseño **responsive** (móvil, tablet y escritorio)
- **Animaciones de scroll** con `IntersectionObserver`
- Botones con `clip-path` y efecto hover personalizado
- Tarjetas de servicios con efectos de elevación y brillo
- Scrollbar personalizada y fondo de cuadrícula
- Un único archivo HTML, sin dependencias de instalación

##  Secciones

| Sección | Descripción |
|---|---|
| **Inicio** | Hero con llamada a la acción |
| **Servicios** | 4 tarjetas: Boosting, Coaching Radiante, Duo Queue Pro y Análisis de VODs |
| **Testimonios** | Opiniones de clientes y valoración |
| **Contacto** | CTA para unirse al Discord |
